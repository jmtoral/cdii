# 🤖 Tema 3: Machine Learning

> 🔜 **Próximamente** — Este tema está en desarrollo.

## 🎯 Objetivos de Aprendizaje (propuestos)

1. Preprocesamiento y feature engineering
2. Clasificación binaria y multiclase
3. Evaluación de modelos (accuracy, precision, recall, F1, AUC-ROC)
4. Validación cruzada y overfitting
5. Interpretabilidad de modelos

## 💡 Ideas de Aplicación con el Dataset

- Clasificar comentarios como hate speech (sí/no) usando features numéricas
- Comparar modelos: Logistic Regression, Random Forest, XGBoost
- Feature importance: ¿qué dimensiones (`insult`, `violence`, etc.) predicen mejor?
- Impacto de la cantidad de datos en el rendimiento del modelo
- Análisis de errores: ¿qué tipo de comentarios clasifica mal el modelo?
